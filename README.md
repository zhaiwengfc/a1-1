# A1 · 前沿产业综合门户（01 低空信息站）

本项目为 **A1 产业门户** 的静态前端工程包，已针对 **GitHub Pages** 部署进行结构优化。

## 已上线板块与核心栏目
- **板块 01：低空信息站**
  - `政策法规`：收录国家部委顶层设计、国家发改委低空司动态、中国民航局（CAAC）CCAR-92 部及深圳特区立法，配备 **A1 政策研究室** 深度原创文章。
  - `创新与供应链信息`：追踪中创新航、亿纬锂能、孚能科技航空动力电池与低压飞控供电系统、奥托立夫安全系统及立邦航空涂料，配备 **A1 供应链智库** 拆解报告。
  - `比赛信息`：聚合数字中国创新大赛低空经济赛道、中国创新创业大赛低空经济领域专业赛（珠海）及美团低空经济与具身智能挑战赛，配备 **A1 赛事观察团** 指南。
  - `产品发布`：覆盖亿航 EH216-S、小鹏汇天“陆地航母”、峰飞“盛世龙”、沃兰特 VE25 与沃飞长空 AE200-100，配备 **A1 飞行器评测中心** 量化横评。
- **板块 02 ~ N（预留扩展槽位）**：空域智算网、产业投融资库、适航与人才院、全球低空峰会及自定义新板块插槽。

## 快速部署至 GitHub Pages
1. 在 GitHub 新建一个公开仓库（例如 `a1-portal`）。
2. 将本压缩包解压后的全部文件（`index.html`、`assets/`、`.nojekyll`、`README.md`）上传并提交至 `main` 分支根目录。
3. 进入仓库 **Settings → Pages**，在 **Build and deployment** 下将 **Source** 设为 `Deploy from a branch`，分支选择 `main` / `/ (root)` 并点击 **Save**。
4. 等待约 1 分钟即可通过 `https://<你的GitHub用户名>.github.io/a1-portal/` 访问。
